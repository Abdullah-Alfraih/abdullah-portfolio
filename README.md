# Abdullah AlFraih Portfolio

A bilingual, static portfolio hosted with GitHub Pages. Open `index.html` to preview it locally.

## Content

- `data.js` contains the profile, experience, education, projects and learning items.
- `app.js` renders the bilingual interface.
- `Abdullah_AlFraih_Resume.pdf` is the current English resume.
- `employee-data-case-study.pdf` summarizes a Power BI practice project using training data.
- `resume.html` displays the English resume in the browser and offers a PDF download.

The HR tracking workbook and internal ERP source are employer-related and are described without publishing source files or employee data. The Google Data Analytics Professional Certificate is in progress.
